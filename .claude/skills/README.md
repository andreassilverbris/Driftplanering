# Skills i det här repot

Matt Pococks skills från https://github.com/mattpocock/skills (MIT-licens, se `LICENSE-mattpocock-skills`),
kopierade hit så att de finns i **alla** sessioner – även i Claude Code i molnet, där globalt installerade
plugins från användarens Mac inte finns.

- Källa: `mattpocock/skills`, commit `abeeaf95660ba9e8b7c753eb38f441ca707a8823` (2026-11-19).
- Med: alla skills i `skills/engineering/` och `skills/productivity/`.
- Inte med: `skills/in-progress/` (ofärdiga) och `skills/misc/` (inte relevanta för projektet).

## Uppdatera

Klona `mattpocock/skills`, kopiera om mapparna under `skills/engineering/` och `skills/productivity/` hit
och uppdatera commit-raden ovan.

## Om du också har pluginet installerat på din Mac

Matt Pocock avråder från att ha både pluginet och kopierade filer, eftersom varje skill då syns två gånger
i Claude Code på Macen. Det är ofarligt men rörigt. Välj ett av:

- behåll kopiorna här (fungerar överallt) och avinstallera pluginet, eller
- behåll pluginet och acceptera dubbletterna i just det här projektet.
